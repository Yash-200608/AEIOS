# AEIOS Definition of Done (DoD)

**Document ID:** GOV-DOD-001  
**Version:** 1.0  
**Status:** Active  
**Date:** 2026-08-01  

A task is **Done** only when **all** of the following are true:

| # | Criterion |
|---|-----------|
| 1 | Implementation is complete for the agreed scope |
| 2 | It compiles cleanly (no unexpected errors/warnings for the target) |
| 3 | Coding standards (STD-FW-001) are satisfied |
| 4 | Unit tests pass |
| 5 | Regression tests pass (or N/A explicitly justified) |
| 6 | Relevant documentation is updated |
| 7 | Traceability is maintained (SR/FR/VT / RTM as applicable) |
| 8 | Evidence package is complete (GOV-REV-001 / PR checklist) |
| 9 | Review is accepted (or Accept with Observations) |

Anything less is **Work in Progress**.

**Related:** No Untested Code Enters Main (GOV-EXEC-001 Rule).
